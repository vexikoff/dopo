# LLM Red Teaming and Bypass Research Framework

## Project Description
This repository contains research materials, methodologies, and tools for testing the robustness (red teaming) and analyzing the bypass mechanisms of safety filters in Large Language Models. The project is intended strictly for academic, educational, and research purposes in the field of artificial intelligence.

## Supported Architectures
Within this project, the safety mechanisms and alignment of the following models and providers are researched:
- Qwen (developed by Alibaba Cloud)
- DeepSeek (developed by DeepSeek AI)
- Kimi (developed by Moonshot AI)
